# Daleel · دليل

**Sharjah, at the right time.** A web guide that tells visitors when and how to visit each place in Sharjah: every stop is timed against crowds, heat and travel. Built by Team Daleel for the Sharjah Tourism Innovation Hackathon 2026.

**Open the app:** https://khadejaahmedkz.github.io/daleel/

Features: a day planner with a real map, picture plates and AR time travel at Al Hisn Fort, hand-built 3D scenes with a walk-in Central Souq and an AR guide, recycling rewards with a GPS check, hands-free control (voice, head pointer, wink to click) from the Sahm project, a welcome page, and full English and Arabic.

This repository holds only the published website. On GitHub Pages the AI guide answers from the app's own data (offline mode); the live Claude guide runs on the Cloudflare deployment.
